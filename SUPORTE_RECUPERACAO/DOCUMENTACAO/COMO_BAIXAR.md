# Como baixar / How to download

**Português:** Em **Releases**, baixe `Nord Kontakt Bridge Portable.exe` (sem instalação) ou `Nord Kontakt Bridge Installer.exe` (instalação com `bin/nord.exe` incluso). O Kontakt 8 permanece necessário para criar instrumentos. Para gerar esses EXEs, consulte `INSTALADOR_LEIA_PRIMEIRO.md`.

**English:** In **Releases**, download `Nord Kontakt Bridge Portable.exe` or `Nord Kontakt Bridge Installer.exe`. The installer includes `bin/nord.exe`; you still need Kontakt 8. To build these EXEs, see `INSTALADOR_LEIA_PRIMEIRO.md`.
